# Broadlink Lifaair for Home Assistant

This repository overrides Home Assistant’s built-in **Broadlink** integration with a version that adds support for the **LIFAair LA330** air purifier.

The LA330 is a quiet air purifier for rooms up to **39 m²**, with **330 m³/h particle CADR**, **140 m³/h formaldehyde CADR**, **HEPA 12** and activated carbon filtration, and built-in readings for **PM2.5, PM10, TVOC, temperature, and humidity**.

## Installation

Add this repository to HACS as a **custom integration**, install it, and restart Home Assistant.
